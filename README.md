# Lyora 🛍️

Lyora is a simple e-commerce web application built with Ruby on Rails.

## Features

- Product listing
- Product details
- Add products to cart
- Increase/decrease quantity
- Remove products from cart
- Automatic cart total
- Checkout page
- Place orders
- Order confirmation
- Responsive design

## Tech Stack

- Ruby
- Ruby on Rails
- SQLite
- HTML
- CSS
- ERB

## Project Purpose

This project was created to practice Ruby on Rails and understand how an e-commerce application works from products and cart management to checkout and orders.
